Question 3 of 5 Data Silos & Semantic RAG
🎙️ Sandeep Singhal (CEO):

"In most US and UK organizations, valuable customer context isn't just stored in standard fields—it's buried inside meeting notes, email threads, PDF contracts, and Knowledge articles. How does Agentforce Coworker unlock that unstructured knowledge without requiring a massive manual data cleanup?"

💬 Mohnish Tak (Verbal Response):

"That's a critical point, Sandeep. In legacy systems, search was purely keyword-matching: if you didn't know the exact account name or case number, you found nothing. Agentforce Coworker is powered by Semantic Search and Data Cloud Vector Indexing. It indexes unstructured data—like Knowledge base articles, attached PDFs, historical case resolutions, and customer emails—into vector embeddings. When a user asks a question in plain English, like 'What was the refund policy exception we made for healthcare clients last quarter?', the Atlas Reasoning Engine performs a semantic RAG query. It surfaces the exact paragraph, provides a clickable source citation link for verification, and drafts the answer instantly. It turns passive file storage into active, searchable intelligence."

Core Talking Point: Semantic Vector Search + Source Citations unifies PDFs, emails, and knowledge into active intelligence.
Question 4 of 5 Human-in-the-Loop & Governance
🎙️ Sandeep Singhal (CEO):

"We’ve all seen headlines about AI hallucinations or autonomous bots making unauthorized promises to customers. When an employee asks Coworker to take an action—like the contact phone update or drafting an outreach email—what guardrails prevent unintended mistakes?"

💬 Mohnish Tak (Verbal Response):

"That distinction is essential: Agentforce Coworker is designed as a Human-in-the-Loop assistant, not a rogue bot. It operates with three distinct safety boundaries: 1. Preview Before Commit: When an action involves writing data or sending an email, the agent displays the proposed changes or generated draft to the user for explicit review and confirmation. 2. Deterministic Actions via Salesforce Flow & Apex: The agent's reasoning engine does not invent backend logic. It delegates tasks strictly to pre-configured Topics and Actions—such as the active Autolaunched Flow we demonstrated today. If an action falls outside its assigned topic scope, the agent politely declines. 3. Native Validation Rules & Governor Limits: Because all updates pass through standard Salesforce APIs, your org’s existing validation rules, duplicate rules, and trigger frameworks execute automatically. If an update violates a business rule, the agent reports the error back to the user gracefully."

Core Talking Point: Human-in-the-loop preview; deterministic Flow/Apex actions; respect for validation rules.
