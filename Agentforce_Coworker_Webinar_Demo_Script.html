ACT 2 Behind The Scenes: 2-Minute Setup (01:30 – 03:15)

🖥️ Action: Click the Gear Icon ⚙️ in the top right header ➔ select Setup.

Step 1: User Security & Permission Set Group

In Quick Find, type Users ➔ click your user ➔ scroll down to Permission Set Group Assignments.

"Everything begins with enterprise security. By assigning the Agentforce Coworker User permission set group, the AI instantly inherits standard Profiles, Field-Level Security (FLS), and Sharing Rules.

If a user doesn't have permission to see an Opportunity amount or a private record in standard Salesforce, the AI will never read or reveal it. There is zero risk of data leakage."

Step 2: The Agentforce Coworker Setup Page

In Quick Find, type Agentforce Coworker ➔ click Get Started with Agentforce Coworker.

"Look at how simple enablement is. From Setup, you simply search for 'Agentforce Coworker' and open this page.

When you flip this toggle to On, Salesforce automatically provisions the underlying Search Agent engine, connects your Data Cloud index, and enables conversational search for all assigned users. No complex coding, no custom integrations."

ACT 5 Boundaries & Limitations in Plain English (07:00 – 08:15)

🎯 Presentation Focus: Proactively address enterprise boundaries as security and governance guardrails.
"Now, before we open for Q&A, a question that every enterprise architect and executive in the room is wondering: 'What are the real-world boundaries, limitations, and guardrails we need to know about?'

Let me share four key considerations in plain language:

1. Single-Seat Developer Limit: In free trial or developer environments like the one I'm demonstrating today, Salesforce allocates strictly one user license and one admin setup seat. It is designed for 1-to-1 evaluation. In full production, you license seats across your teams.

2. The Data Cloud Backbone: Coworker doesn't operate in a vacuum—it requires Data Cloud running behind the scenes. Think of Data Cloud as the AI's long-term memory and indexing engine; without it, Coworker cannot ground its answers across your CRM and enterprise documents.

3. Document & Sync Boundaries: While Coworker can search external files from SharePoint or Google Drive, documents larger than 75 megabytes are not indexed. Also, external documents sync on a scheduled cadence (typically hourly)—so if you edit a Word doc in SharePoint, allow a little sync time before expecting Coworker to find the update.

4. Strict Security Mirroring: Coworker never peeks around corners. If a record or field is restricted from a user by your Sharing Rules or Field-Level Security, Coworker will state that no information was found. It respects your existing security model 100%."
